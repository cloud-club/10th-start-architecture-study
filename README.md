# 10th-start-architecture-study


백엔드 개발자로서 단순히 기술을 사용하는 것을 넘어, **요구사항에 맞는 시스템 아키텍처를 직접 설계하고 기술 선택의 근거를 설명하는 역량**을 기르기 위한 스터디입니다.

『가상 면접 사례로 배우는 대규모 시스템 설계 기초 2』를 기반으로 메시지 큐, 결제 시스템 등 실무와 밀접한 사례를 학습합니다.

책을 읽는 것 보다 직접 그림을 그려보는것에 집중하여, **직접 설계 → 설계 공유 및 토론 → 책을 통한 보충 학습** 방식으로 진행됩니다.

매주 온라인으로 모여 주어진 주제에 대해 각자 아키텍처를 설계하고, 서로의 설계를 비교하며 다양한 기술적 선택과 트레이드오프를 얘기하려 합니다.

1주 차에는 사전 지식이 전혀 없는 상태에서 호텔 예약 시스템을 설계하고, 8주 차에 동일한 요구사항으로 다시 설계하여 학습 전후의 성장 과정을 비교할 예정입니다.
